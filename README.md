# hack-assembler
「コンピュータシステムの理論と実装」第6章のアセンブラをKotlinで記載したものです。

## 全体の流れ
2パス・アセンブラ方式で、.asmファイルを.hackファイルに変換します。

- 第1パス: ラベル宣言 `(xxx)` について、 `xxx` をシンボルテーブルに追加する。
- 第2パス: 各行をパースし、アセンブリ命令をバイナリコードに変換する。 
  - A命令: シンボルテーブルを用いて `@xxx` の `xxx` を解決する。もしシンボルテーブルに存在しなければ、新しい変数とみなしてテーブルに追加する。
  - C命令: comp, dest, jumpのそれぞれを変換する。
